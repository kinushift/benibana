# sumire
Rust製のUnicode対応入力検証ライブラリ

## 概要  
テキスト＆文字数制限(usize)を使用し、Unicodeの構造を考慮した入力検証を行う。

書記素クラスタ・Unicodeスカラー値を利用し、特殊な文字などを検証している
  
**処理されること**: 
1. 制御文字・見えない文字・向きなどを変える文字を取り除く
2. 前後の空白を取り除く
3. 書記素での上限確認
4. 異常な文字の検出

   \- スカラー値13個以上でできた1文字(長すぎる絵文字の連結など)

   \- 異体字セレクタの連続

   \- イングランド・スコットランド・ウェールズの旗以外のタグ文字

## 呼び出せる関数
### sanitize_line(text: String, max_chars: usize)
\- テキストの改行を削除し、サニタイズを実行する

### sanitize_text(text: String, max_chars: usize)
\- テキストの改行をのこして、サニタイズを実行する

どちらも `Result<String, SumireError>` を返します。

## エラー
\- `Empty` : 取り除いた結果、何も残らなかった。

\- `TooLong` : 上限を超えた。

\- `InvalidCharacter` : 使えない文字が含まれていた。

## 依存
\- memchr

\- unicode-segmentation

### 依存の管理
\- 依存は2つのみ(どちらもほかのcrateに依存していない)

\- `Cargo.lock` をコミットして、依存のバージョンを固定

\- `cargo audit` で既知の脆弱性を確認

\- `cargo vet` で依存のコードを監査

## テスト

\- 実行回数: 約26億回

\- クラッシュ発生回数: 0回

\- 検査項目: panicしないか、取り除いた文字が残らないか、前後に空白が残っていないか、2回実行しても同じ結果になるか
